# SavanaEdit Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Space | Play or pause the active preview |
| Ctrl+N | New Project |
| Ctrl+O | Open Project |
| Ctrl+S | Save Project |
| Ctrl+Shift+S | Save Project As |
| Ctrl+Z | Undo timeline edit |
| Ctrl+Shift+Z | Redo timeline edit |
| Ctrl+B | Split selected clips at playhead |
| Ctrl+C | Copy selected clips |
| Ctrl+V | Paste clips at playhead |
| Delete | Delete selected clips |
| S | Toggle timeline snapping |
| Left / Right | Move playhead by one project frame |
| Shift+Click | Add a timeline clip to selection |

Shortcuts are ignored while typing in a text field, prompt, or settings control.
